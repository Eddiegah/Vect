1. What is Vect?

Vect is a programming language — a way to give instructions to a computer. But it was designed with a special purpose: to make scientific computing feel like a natural part of the language.

In most programming languages, if you want to work with vectors (lists of numbers), matrices (grids of numbers), or calculus (differentiation, integration), you have to import a library — a separate toolkit. The code ends up looking cluttered and complicated.

In Vect, these things are built into the language itself. Here is what that means in practice:

# This is Vect. You don't import anything.
# A vector is just written with square brackets:
var velocity = [10.0, 15.0, 0.0]

# Differentiation is just an operator — like + or *
sym f(x) = x**2 + 3*x
print(eval(d/dx(f(x)), x=2.0))   # prints 7.0

By the end of this guide, you will understand every line of that code and be able to write your own.

4. The REPL — Your Interactive Playground

Instead of writing a file, you can type Vect code directly and see results instantly. This is called the REPL (Read-Eval-Print Loop). Think of it as a calculator you can have a conversation with.

venv\Scripts\vect

You will see a prompt: vect>. Now type and press Enter after each line:

vect> print(10 + 5)
15
vect> print(3.14 * 2.0)
6.28
vect> print("Vect is great")
Vect is great
vect> exit

Type exit to leave the REPL. Type help to see all available commands.

✏️ Try it yourself

Start the REPL and try calculating: 100 / 4, 7 ** 2 (seven squared), and 15 % 4 (remainder).

var age    = 21
var height = 1.82

var passed = true

# Use them

Programs become useful when they can make decisions. The if statement lets your program choose what to do based on a condition.

var temperature = 38.5

var score = 85

if score >= 90 {

7. Repeating Things — Loops

Loops let you repeat the same instructions multiple times without writing them out over and over.

while loop — repeat until a condition is false

var count = 1
while count <= 5 {
    print(count)
    count = count + 1
}
# prints: 1  2  3  4  5

for loop — go through each item in a list

for x in [10.0, 20.0, 30.0, 40.0] {
    print(x * 2.0)
}
# prints: 20  40  60  80

Sum of numbers 1 to 100

var i     = 1
var total = 0
while i <= 100 {
    total = total + i
    i = i + 1
}
print(total)   # 5050
✏️ Try it yourself

Write a loop that prints the squares of the numbers 1 through 10 (1, 4, 9, 16, ..., 100). Hint: x * x gives the square of x.

8. Writing Your Own Functions

A function is a named block of code you can run as many times as you want by calling its name. Functions prevent you from writing the same code repeatedly.

# Define a function
fn greet(name: string) {
    print("Hello, " + name + "!")
}

# Call it as many times as you like
greet("Alice")
greet("Bob")
greet("Vect")

Functions that return a value

fn square(n: int) -> int {
    return n * n
}

print(square(5))    # 25
print(square(12))   # 144

Functions without type annotations (v3 feature)

You don't have to write the types — Vect figures them out:

fn double(x) { return x * 2 }

print(double(7))     # 14   works with int
print(double(3.5))   # 7.0  works with float too

Recursive functions (functions that call themselves)

fn factorial(n: int) -> int {
    if n <= 1 { return 1 }
    return n * factorial(n - 1)
}
print(factorial(5))    # 120  (5 × 4 × 3 × 2 × 1)
print(factorial(10))   # 3628800
✏️ Try it yourself

9. Working with Text — Strings and F-Strings

Strings are text values. You put them in double quotes. F-strings let you embed variable values directly inside a string.

var name  = "Eddie"
var score = 95
var grade = "A"

# Without f-string (old way — harder to read)
print("Name: " + name + ", Score: " + str(score))

# With f-string (much cleaner!)
print(f"Name: {name}, Score: {score}, Grade: {grade}")

# You can put any expression inside {}
print(f"Double the score: {score * 2}")
print(f"Square root of 144: {sqrt(144.0)}")
Name: Eddie, Score: 95, Grade: A Double the score: 190 Square root of 144: 12.0
✏️ Try it yourself

Create variables for a product name, its price, and a discount percentage. Use an f-string to print: "Product: [name], Original: [price], After 20% discount: [calculated price]"

10. Vectors — Your First Scientific Feature

A vector is an ordered list of numbers. In physics, a velocity vector might be [10.0, -3.0, 0.0] (speed in x, y, z directions). In data science, a vector might hold a student's exam scores.

In Vect, vectors are written with square brackets and are a first-class part of the language — you don't need to import anything.

# Create vectors
var v1 = [1.0, 2.0, 3.0]
var v2 = [4.0, 5.0, 6.0]

print(v1)              # [1, 2, 3]
print(v1 + v2)         # [5, 7, 9]   add each pair
print(v1 * 3.0)        # [3, 6, 9]   multiply each by 3
print(v1[0])           # 1.0         first element
print(v1[2])           # 3.0         third element (0-based)
print(len(v1))          # 3           how many elements

The dot product — a special operation

The dot product multiplies matching elements and adds them up. It is written with a middle dot · (copy-paste from here, or press Alt+0183 on Windows).

var a = [1.0, 2.0, 3.0]
var b = [4.0, 5.0, 6.0]
print(a · b)   # 32.0   (1×4 + 2×5 + 3×6 = 4+10+18)

Useful vector functions

print(norm(v1))         # 3.742  magnitude / length of vector
print(normalize(v1))    # unit vector (magnitude = 1)
print(zeros(4))         # [0, 0, 0, 0]
print(ones(3))          # [1, 1, 1]

Real example — average of a list of scores

var scores = [88.0, 92.0, 76.0, 95.0, 84.0]
var total  = 0.0
for s in scores {
    total = total + s
}
var average = total / 5.0
print(f"Average score: {average}")
✏️ Try it yourself

Create a velocity vector [3.0, 4.0, 0.0]. Print its norm (this is the speed). Then print the unit vector (direction only).

11. Matrices — Grids of Numbers

A matrix is a grid of numbers, like a spreadsheet. A 2×2 matrix has 2 rows and 2 columns.

var A = [[1.0, 2.0],
         [3.0, 4.0]]

print(A)            # shows the whole matrix
print(A[0])         # [1, 2]  first row

Matrix multiply — the @ operator

var A = [[1.0, 2.0], [3.0, 4.0]]
var B = [[5.0, 6.0], [7.0, 8.0]]
print(A @ B)        # [[19,22],[43,50]]

Transpose — flip rows and columns

print(T(A))         # [[1,3],[2,4]]

Linear algebra

print(det(A))       # -2.0  determinant
print(inv(A))       # matrix inverse

# Solve the system: 1x + 2y = 5,  3x + 4y = 6
var b = [5.0, 6.0]
print(solve(A, b))   # the values of x and y
✏️ Try it yourself

Create a 3×3 identity matrix (1s on the diagonal, 0s everywhere else). Multiply it by another matrix and verify the result equals that same matrix.

12. Symbolic Differentiation — Calculus Made Easy

This is Vect's most powerful feature. Differentiation means finding the rate of change of a mathematical function — the slope of a curve at any point.

In Vect, you do not need to know the calculus rules. You just write d/dx(...) and Vect calculates the exact derivative for you.

Three steps to differentiate

Step 1: Define a symbolic function with sym

sym f(x) = x**2 + 3*x + 1

This tells Vect that f is a mathematical function of x.

Step 2: Differentiate with d/dx

var df = d/dx(f(x))
print(df)   # 2*x + 3

Vect calculates the exact derivative. The result is a symbolic expression you can print.

Step 3: Evaluate at a specific number with eval

print(eval(df, x=0.0))   # 3.0  — the slope at x=0
print(eval(df, x=2.0))   # 7.0  — the slope at x=2
print(eval(df, x=5.0))   # 13.0 — the slope at x=5

Any variable name works

Use d/dt for time, d/dr for radius — whatever makes sense for your problem:

# Physics: ball thrown upward at 20 m/s
sym height(t) = 20.0*t - 4.9*t**2

var velocity = d/dt(height(t))
print(velocity)                    # 20.0 - 9.8*t

print(eval(velocity, t=0.0))       # 20.0 m/s at launch
print(eval(velocity, t=2.04))      # ≈ 0  m/s at peak
print(eval(velocity, t=4.0))       # negative = falling

More examples

# Kinetic energy: KE = ½mv²  (m = 2 kg)
sym KE(v) = 0.5 * 2.0 * v**2
var momentum = d/dv(KE(v))     # dKE/dv = mv (momentum!)
print(momentum)                # 2.0*v
print(eval(momentum, v=10.0))  # 20.0 kg·m/s

# Circle area: dA/dr = circumference
sym area(r) = 3.14159 * r**2
var circ = d/dr(area(r))
print(eval(circ, r=5.0))       # 31.4159

Define sym g(x) = x**3 - 6*x**2 + 9*x. Differentiate it. Then find the two x values where the slope is zero (hint: try x=1.0 and x=3.0 in eval).

13. Integration — Area Under a Curve

Integration is the reverse of differentiation. It calculates the total area under a curve between two points — used to find distance from velocity, work from force, and many other real-world values.

# Area under x² from 0 to 3
sym f(x) = x**2
var area = integral(f(x), "x", 0.0, 3.0)
print(area)   # 9.0  (exact answer)
# Work = integral of force over distance
sym force(x) = 2.0*x + 1.0
var work = integral(force(x), "x", 0.0, 5.0)
print(work)   # 30.0 Joules
# Distance from velocity (indefinite integral)
sym vel(t) = 20.0 - 9.8*t
var position = integral(vel(t), "t")   # no limits = symbolic
print(position)                         # 20.0*t - 4.9*t**2
Definite vs Indefinite

Definite: integral(f(x), "x", 0.0, 3.0) — gives a number (area between 0 and 3).
Indefinite: integral(f(x), "x") — gives a symbolic expression (the antiderivative).

✏️ Try it yourself

A car accelerates with force F(t) = 3t (Newtons). Find the total work done from t=0 to t=4 seconds using integral().

14. Plotting — Drawing Graphs

The plot() function draws a graph of any symbolic function and saves it as a PNG image file.

# Plot a parabola
sym f(x) = x**2 - 4
plot(f(x), x, -3.0, 3.0, "Parabola: x² - 4")
print("Graph saved as vect_plot.png")
# Plot a projectile's path
sym height(t) = 20.0*t - 4.9*t**2
plot(height(t), t, 0.0, 4.1, "Projectile Height")
# Plot your own data
var years  = [2019.0, 2020.0, 2021.0, 2022.0, 2023.0]
var scores = [72.0, 78.0, 85.0, 88.0, 92.0]
plot_xy(years, scores, "Performance over time")

After running any of these, find vect_plot.png in your Vect folder and open it to see the graph.

15. Using Libraries — Multi-File Imports

When your programs grow, you can split code across multiple files. Vect comes with three ready-to-use library files in the stdlib/ folder.

# Use the physics library
import "stdlib/physics.vect"

print(kinetic_energy(70.0, 10.0))       # 3500.0 J
print(potential_energy(70.0, 5.0))      # 3430.0 J
print(free_fall_height(20.0, 2.0))      # 20.4 m
# Use the vectors library
import "stdlib/vectors.vect"

var exam_scores = [65.0, 78.0, 82.0, 91.0, 55.0]
print(f"Average: {vec_mean(exam_scores)}")
print(f"Highest: {vec_max(exam_scores)}")
print(f"Lowest:  {vec_min(exam_scores)}")
# Use the math library
import "stdlib/mathlib.vect"

print(clamp(150.0, 0.0, 100.0))   # 100.0 (capped at max)
print(lerp(0.0, 200.0, 0.5))      # 100.0 (halfway)

Creating your own library

Create a file called mylib.vect with useful functions. Then use it in any program:

# mylib.vect
fn celsius_to_fahrenheit(c: float) -> float {
    return c * 9.0 / 5.0 + 32.0
}

fn fahrenheit_to_celsius(f: float) -> float {
    return (f - 32.0) * 5.0 / 9.0
}
# main.vect
import "mylib.vect"

print(celsius_to_fahrenheit(100.0))   # 212.0 (boiling)
print(fahrenheit_to_celsius(98.6))    # 37.0 (body temp)

16. Your Graduation Project

You have learned everything you need to write a real Vect program. Here is your challenge — a complete physics simulation that uses every feature from this guide.

Graduation Project

Projectile Motion Analyser

Create a file called projectile.vect and complete it step by step:

# projectile.vect — Complete projectile motion analyser
import "stdlib/physics.vect"

# ── 1. Launch parameters ─────────────────────────────
var launch_speed = 25.0     # m/s
var mass         = 0.5      # kg (e.g. a cricket ball)

# ── 2. Symbolic model ────────────────────────────────
sym height(t) = launch_speed * t - 4.9 * t**2

# ── 3. Differentiate to get velocity ─────────────────
var velocity = d/dt(height(t))
print(f"Velocity formula: {velocity}")

# ── 4. Find peak time (when velocity = 0) ────────────
var peak_time = launch_speed / 9.8
print(f"Peak at t = {peak_time} seconds")

# ── 5. Peak height ───────────────────────────────────
var peak_height = eval(height(t), t=peak_time)
print(f"Peak height = {peak_height} metres")

# ── 6. Energy calculations ───────────────────────────
var ke = kinetic_energy(mass, launch_speed)
var pe = potential_energy(mass, peak_height)
print(f"Launch KE: {ke} J")
print(f"Peak PE:   {pe} J")

# ── 7. Plot the trajectory ───────────────────────────
var flight_time = 2.0 * peak_time
plot(height(t), t, 0.0, flight_time, "Projectile Trajectory")
print("Graph saved to vect_plot.png")

Run it:

venv\Scripts\vect run projectile.vect
